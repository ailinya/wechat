# Tasks

本清单跟踪整个项目开发，实施进度以复选框、代码及验收证据共同判断；已有完成记录保留，新增能力不因原任务已勾选而视为完成。阶段目标、依赖图、设计决策及能力规格索引见 [design.md](design.md)；产品依据见 [PRD](../../../doc/instruction/PRD.md)，界面参考 `doc/html/`。实施和验收须同时满足对应 `specs/<capability>/spec.md` 的 Requirements 与 Scenarios。每项应在一次工作会话内完成；若实际范围超过一次会话，先保留原编号并拆成更小的检查项。

执行规则：先满足阶段依赖，再按任务中的必要依赖推进；未注明同阶段依赖的任务仅继承阶段前置条件。接口任务负责契约、schemas 与客户端类型；后端任务负责服务、路由及适配器；前端任务负责页面与联调，避免重复实现同一业务逻辑。每个实现任务同时完成其必要单元检查，独立测试任务用于跨组件验证。当前规划完成不勾选开发项。
