# 应用导航与页面交互

## Purpose

为平台的八个业务模块提供一致的导航、查询上下文、异步进度和操作反馈，使用户能从待办进入具体对象，并在刷新、失败或权限不足时理解当前情况。页面展示须对应真实服务端数据，原型和模拟能力必须明确标识。

## ADDED Requirements

### Requirement: 八模块导航边界
系统 SHALL 提供工作台、采集管理、智能创作、内容管理、素材库、数据统计分析、账号管理和系统设置八个一级导航；编辑、审核、排版和发布 MUST 作为对应模块子流程组织。

#### Scenario: 从内容列表进入编辑与发布
- **WHEN** 有权限的用户从内容管理打开文章编辑、排版或发布配置
- **THEN** 页面保留内容管理上下文，不新增一级导航模块

### Requirement: 查询上下文恢复
系统 SHALL 通过可恢复的页面地址表达列表筛选、分页、排序和详情资源标识，使刷新和返回列表保持查询上下文。

#### Scenario: 返回已筛选列表
- **WHEN** 用户按状态和时间筛选列表后查看详情，再返回或刷新列表
- **THEN** 系统恢复原筛选、分页和排序，并从服务端读取相应结果

### Requirement: 明确的页面状态
页面 MUST 区分加载、无数据、失败、无权限以及业务条件不足；缺少真实接入的功能 MUST 明确标记待接入或演示状态。

#### Scenario: 列表请求失败
- **WHEN** 读取素材列表的请求失败
- **THEN** 页面显示失败及恢复入口，不把请求失败展示为没有素材

#### Scenario: 演示数据展示
- **WHEN** 页面使用 fixture 或静态原型数据
- **THEN** 页面明确提示演示状态，不宣称完成真实采集、模型调用或微信发布

### Requirement: 业务操作反馈与跨模块跳转
系统 SHALL 根据服务端结果显示操作反馈并传递真实资源标识；异步受理 MUST 只表示任务已创建，不表示业务成功。

#### Scenario: 采集入库后跳转
- **WHEN** 服务端完成一条采集结果的素材入库并返回素材标识
- **THEN** 页面显示真实入库结果并能打开对应素材详情及来源信息

#### Scenario: 创作仅被受理
- **WHEN** 创作请求返回异步任务标识而尚无生成结果
- **THEN** 页面显示等待或执行状态，不显示文章生成成功

### Requirement: 可恢复的异步进度
系统 SHALL 根据持久化任务标识查询阶段、进度和失败原因；页面刷新后 MUST 能恢复任务展示，终态不再持续查询，临时网络错误不得改写业务终态。

#### Scenario: 刷新正在执行的任务
- **WHEN** 用户刷新创作任务页且任务仍在运行
- **THEN** 页面根据同一任务标识恢复阶段与进度，不重复提交创作

### Requirement: 前端权限提示与未保存编辑
页面 SHALL 根据有效权限提示可执行操作，并在用户离开有未保存文章修改的页面时提示可能丢失的变更；权限校验结果 MUST 以服务端为准。

#### Scenario: 编辑未保存时离开
- **WHEN** 用户修改文章正文但未保存并尝试跳转其他页面
- **THEN** 系统提示存在未保存修改，由用户决定继续离开或保留编辑
