# 素材资产管理

## Purpose

将采集、上传、网页链接、人工文字、历史文章及企业资料沉淀为长期可复用素材，保留正文版本、原始来源和附件。素材管理必须区分完全重复与事件新进展，保障文章引用的历史内容可追溯，并支持分类、标签、收藏及生命周期管理。

## ADDED Requirements

### Requirement: 多来源素材与完整中文正文
系统 SHALL 接收已支持的采集、文档/图片上传、网页链接、手动文字、历史文章和企业资料，保存可用来源及附件；文本正文 SHALL 使用 Markdown 表达并完整保留中文内容。

#### Scenario: 保存中文资料
- **WHEN** 用户录入包含中文、标点和多段落的资料并保存
- **THEN** 详情及再次编辑读取的正文保持完整，来源类型和入库时间可见

### Requirement: 不可变正文修订
系统 MUST 在正文修改时创建新修订，保留旧正文与来源；当前版本指向同一素材的修订，历史引用 MUST 继续指向当时实际使用的版本。

#### Scenario: 已引用素材被修改
- **WHEN** 一篇文章已引用素材旧版，素材随后更新正文
- **THEN** 默认详情显示新版，文章仍能查看旧版引用内容，不被新版静默替换

### Requirement: 完全重复不重复创建
系统 MUST 将确认为完全重复的采集结果关联至已有素材，保留结果与来源历史；重复请求和并发入库不得多次创建同一入库产物。

#### Scenario: 相同结果并发入库
- **WHEN** 两个请求同时将同一采集结果入库
- **THEN** 两个请求得到一致的素材关联，素材和首修订只产生一次

### Requirement: 事件新进展保留
系统 MUST 为同一事件的有效新进展保留独立新增内容，并关联历史素材；仅有标题或指纹相似不得作为丢弃新信息的充分依据。

#### Scenario: 相同事件出现新数据
- **WHEN** 新结果与历史素材主题相同但包含有效新增事实或数据
- **THEN** 系统保留新素材并记录更新关系，原素材和正文仍可访问

### Requirement: 分类标签与个人收藏
系统 SHALL 支持分类层级、标签、按条件筛选、个人收藏及声明支持的批量操作；分类不得形成循环，收藏 MUST 按用户隔离。

#### Scenario: 不同用户收藏同一素材
- **WHEN** 用户甲收藏素材而用户乙查询自己的收藏
- **THEN** 甲的收藏不自动出现在乙的收藏中，素材自身仍为共享业务资产

#### Scenario: 分类形成循环
- **WHEN** 用户尝试将父分类移动到其子分类之下
- **THEN** 系统拒绝该操作并保留原分类结构

### Requirement: 使用状态与长期复用
系统 SHALL 区分待筛选、待使用、已使用、部分使用、已归档、重复素材；已使用不表示不可复用，归档或删除操作 MUST 不破坏已有引用的正文、来源及历史关系。

#### Scenario: 素材再次用于创作
- **WHEN** 用户在允许包含已使用素材的策略中选择曾被引用的素材
- **THEN** 系统允许再次使用并保留所有创作及文章引用历史

#### Scenario: 删除已有引用的素材
- **WHEN** 用户请求删除已经被文章引用的素材
- **THEN** 系统按保留策略拒绝破坏性删除或仅隐藏/归档，历史引用仍能读取原正文及来源

### Requirement: 双向引用追踪
系统 SHALL 展示素材关联的采集结果、来源、创作记录和引用文章版本，同时支持从文章返回当时使用的素材正文；创作候选与文章实际引用 MUST 可区分。

#### Scenario: 查询素材引用链
- **WHEN** 用户打开已参与创作的素材详情
- **THEN** 系统列出真实创作和引用文章，可区分仅候选未采用的关系，并能打开对应文章版本

### Requirement: 跨来源去重与语义判断分层
系统 MUST 用版本化正文规范化 hash 识别跨 URL 完全重复并保留全部来源；非完全重复 SHALL 先查找有限历史候选，再按需使用素材分析能力比较。URL 相同或 hash 改变不能单独证明事件新进展，语义重复及不确定结论默认需人工确认。

#### Scenario: 不同网站转载相同正文
- **WHEN** 两个来源的文章规范化正文完全相同并并发入库
- **THEN** 系统只创建一份素材，两条采集结果均可追溯，重复项不额外调用 LLM

#### Scenario: 原网页仅修改格式而不是新增事实
- **WHEN** 同一 URL 的规范化正文 hash 发生变化，但没有可定位的新增事实证据
- **THEN** 系统不自动建立 update_of，保留待筛选依据及原始内容，不用 hash 差异伪造事件新进展

#### Scenario: 其他网站报道同事件的新事实
- **WHEN** 不同 URL 的候选经分析具有可定位的新增事实且入库条件通过
- **THEN** 系统可创建新素材并关联旧素材修订及判断依据，旧正文与来源保持不变
