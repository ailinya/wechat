# 文件与附件访问

## Purpose

为图片、文档、封面和其他附件提供受控上传、校验登记及授权下载能力，使二进制文件与业务正文分别管理。文件是否可用须由服务端验证，浏览器不能凭任意对象键取得他人文件，也不能因上传提示成功而跳过业务登记。

## ADDED Requirements

### Requirement: 限定范围的上传授权
系统 SHALL 仅为有权限的用户签发限定对象键、有效期、大小和类型的上传授权；授权 MUST 不暴露长期存储凭据。

#### Scenario: 申请合法上传
- **WHEN** 用户申请上传允许类型且大小在限制内的文件
- **THEN** 系统返回对应对象的短期授权及限制，不能据此写入其他对象

#### Scenario: 不允许的上传参数
- **WHEN** 用户申请超出限制大小或不支持类型的上传
- **THEN** 系统拒绝授权并说明限制，不创建已完成文件记录

### Requirement: 后端校验完成登记
文件登记 MUST 验证上传申请人、授权有效性、实际对象存在及内容大小和类型；伪造完成请求不得创建可用文件，同一授权重复完成不得重复登记。

#### Scenario: 上传后完成登记
- **WHEN** 实际文件满足原授权限制且申请人提交完成请求
- **THEN** 系统返回可关联业务对象的文件标识，并记录对象元数据

#### Scenario: 对象不符或不存在
- **WHEN** 调用方提交不存在对象、其他用户对象或不符合限制的完成请求
- **THEN** 系统拒绝登记，不将该对象关联为可用附件

### Requirement: 受控下载与关联
系统 MUST 校验用户对文件及关联业务资源的访问权限后提供短期下载授权；知道文件标识或对象键不得自动取得访问权。

#### Scenario: 无权下载附件
- **WHEN** 无附件所属资源访问权限的用户请求下载授权
- **THEN** 系统拒绝请求，不返回可用下载地址或长期凭据

### Requirement: 原文件与正文分别保留
系统 SHALL 为已登记附件保留原文件及可用元数据，业务正文使用独立文本修订关联文件；文件解析失败 MUST 不把空正文标为解析成功。

#### Scenario: 文档解析失败
- **WHEN** 已登记的文档因损坏或格式不支持而无法解析
- **THEN** 系统仍保留原文件关联，展示解析失败及原因，并允许按授权下载原文件或执行支持的重试

### Requirement: 上传失败可恢复
系统 SHALL 区分上传失败与业务登记失败，允许重新授权或安全重试登记；未完成登记的对象 MUST 不显示为可用业务附件。

#### Scenario: 已直传但登记响应丢失
- **WHEN** 文件实际已上传且用户重试原完成登记请求
- **THEN** 系统返回同一文件标识或明确恢复结果，不创建第二个附件对象
