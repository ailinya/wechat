# 阶段8：运营统计与平台管理

工作台仅聚合用户有对应业务读取权限的数据；报表和导出还要求 analytics:read/export。不同来源的发布数据分别统计：接口发布单、草稿同步、人工登记。草稿成功不进入发布成功率分母；人工登记不冒充接口验证。

报表采用统一事实行：来源ID、标题、当前结果、归属时间、来源、账号、关联任务、尝试次数、数量、可用指标。查询、趋势、分组、总计和CSV使用同一SQL过滤。区间为用户声明IANA时区的本地日期[start_date,end_date)，转换UTC查询；最多366天，默认最近30天。以事实创建时间归属任务/素材、审核记录创建时间归属审核、人工登记时间归属人工发布。逻辑创作任务一行，通用作业重试只增加attempts；重新生成是新任务。接口发布单一行，尝试单独累计；人工登记每交付一行。成功率=成功/(成功+明确失败)，pending/running/unknown/cancelled/insufficient/partial均排除；采集partial单独展示。审核通过率=approve/全部审核记录。素材报表一素材一行，引用数按不同文章去重，并展示复用(引用文章数>1)。采集来源分布、任务/规则表现和失败原因从相同明细分组。

筛选支持数据类型、日期/时区、账号、采集任务、创作任务。各类型仅显示支持的筛选；不支持组合返回422，禁止静默忽略。素材按真实采集来源/创作采用关联筛选(用EXISTS防重)；发布和审核可按文章关联创作任务筛选。账号指标为所选区间内最新采集快照，无快照仍返回账号及不可用字段。微信datacube只读采集按昨日/指定日请求，记录时间、外部文章ID及实际可用字段；人工链接不能可靠对应msgid时不强行关联。失败、空响应、缺失字段保留NULL及原因，禁止补零。

通知采用站内渠道，其他渠道明确禁用且不发送外部消息。定时任务读取持久业务结果/审核事件，为有对应读取权限的活跃用户投递，接收人/事件键/渠道唯一；批次上限且重复运行无重复通知。偏好更新时间屏蔽关闭期间的历史可选事件，读取时再次检查当前业务权限；只允许本人标记已读。事件来源为真实运行/修订/审核/attempt/人工登记，无伪造任务。任务监控与日志独立授权；监控不返回payload/原始last_error，日志详情递归脱敏并不暴露未清理字符串。

平台名称、介绍、文字标识和时区保存在system_settings单例，配置版本防止覆盖。模型/搜索沿用既有配置和连接测试，凭据仅受控环境变量引用；微信绑定/检测沿用账号页，RustFS仅提供环境配置摘要与只读连接检查，运行期密钥不经浏览器回显或覆盖。用户/角色写入补审计、无效关联明确拒绝。所有写接口要求CSRF。

页面沿用八模块导航；工作台展示概览/最近文章/动态/待办/异常和通知入口；统计提供日期/时区/维度筛选、趋势、分组、明细和完整CSV导出；设置含平台/模型搜索/用户/角色/接口/通知/日志/任务子页面。未配置或无权限的功能明确显示原因。
