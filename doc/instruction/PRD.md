# 智媒助手产品需求文档（PRD）

**版本：** V1.0  
**产品名称：** 智媒助手  
**产品形态：** 网页管理后台  
**产品定位：** 基于AI技术的微信公众号智能内容运营管理平台

---

# 一、产品概述

## 1.1 产品目标

智媒助手是一套集信息采集、素材管理、AI内容创作、文章编辑、人工审核、微信公众号发布和运营数据分析于一体的智能化管理平台。

平台通过自动化工作流，实现从外部信息采集到微信公众号文章发布的完整业务闭环。

核心目标：

1. 自动采集互联网公开信息和行业资讯。
2. 自动将采集信息整理并保存到素材库。
3. AI自动分析素材，识别有价值的信息和创作主题。
4. 根据素材库中的信息自动生成微信公众号文章。
5. 支持人工编辑、排版和审核。
6. 审核通过后由运营人员确认发布。
7. 对采集、创作、审核、发布全过程进行管理和统计。

## 1.2 产品核心原则

- 采集自动化：支持定时采集和手动采集。
- 素材资产化：所有有价值的信息可以长期保存和重复使用。
- 创作智能化：AI根据采集素材自动分析并生成文章。
- 内容可追溯：每篇文章可以追溯到使用的原始素材。
- 审核人工化：AI生成文章后必须经过人工审核。
- 发布可控化：默认不允许AI未经人工确认直接发布。
- 流程可管理：每个任务均有执行记录、状态和异常信息。

# 二、平台整体模块架构

平台共设置8个一级导航模块。

| 序号 | 一级模块 | 核心职责 |
|---|---|---|
| 1 | 工作台 | 展示平台整体运营情况和任务动态 |
| 2 | 采集管理 | 负责外部信息采集和采集任务管理 |
| 3 | 智能创作 | 负责素材分析、主题提取和AI文章生成 |
| 4 | 内容管理 | 负责文章编辑、排版、审核和发布 |
| 5 | 素材库 | 负责素材存储、分类、检索和资产管理 |
| 6 | 数据统计分析 | 负责采集、创作、发布和运营数据分析 |
| 7 | 账号管理 | 负责微信公众号授权、账号配置和发布账号管理 |
| 8 | 系统设置 | 负责AI模型、用户权限、接口和平台配置 |

说明：AI排版功能集成在内容管理的文章编辑页面中，不单独设置一级模块。

## 4.3 核心业务规则

1. 采集任务可以定时执行，也可以人工触发。
2. 采集完成后，系统根据配置自动入库。
3. 支持人工选择采集结果加入素材库。
4. 自动识别重复信息，避免重复创建素材。
5. 新信息和已有信息需要建立关联。
6. 同一事件出现新的进展时，应保留有价值的新内容，不应简单判定为重复。
7. 采集任务完成后，可以触发关联的自动创作规则；启用素材分析时须等当前正文分析及入库就绪后再通知规则检查，失败或待筛选资料不自动触发创作。

## 4.4 主题搜索与采集增强（新增需求，待实现）

1. 主题搜索任务提供主题、关键词、时间范围、可选网站范围和最大采集篇数；指定来源任务提供来源及可选关键词。关键词用于主题查询并按标题/正文任一短语筛选，语义相关性由可选分析提供。
2. RSS 和栏目页先发现多篇文章链接，再分别抓取正文；设置分页与候选数量上限，重复链接不反复抓取。来源首页、RSS 整体和搜索摘要不能被当作完整文章。
3. 提取文章标题、正文、可用发布时间及原文证据；时间窗口以本次执行开始时间固定。缺失或冲突日期显示未知/待筛选，不用采集时间替代，不自动入库。
4. 支持开启 LLM 素材分析，生成摘要、分类标签建议、主题相关性与理由、关键事实及原文引用。分析是资料处理和建议，不代表已完成事实核验。
5. 完全重复先用确定性规则识别；疑似重复或同事件资料再按需比较新增事实。语义重复和不确定结论默认人工确认，有效新进展保留独立素材及关联。
6. 搜索、抓取、解析、分析和入库分别显示进度、结果和失败原因。零搜索结果不等于服务故障；部分失败保留已完成成果，分析重试复用已有正文。
7. 模型分析默认仅建议，可配置只补空且未经人工维护的字段；重新分析不能覆盖人工编辑。人工采用建议须检查版本冲突；未知分类/标签须确认后创建。
8. 分析失败不自动入库；用户可明确保留为待筛选素材并记录原因，后续分析成功或人工确认可用后才进入就绪流程。
9. 旧任务默认保持指定来源、分析关闭，升级不重跑历史任务。启用分析需可用模型；配置缺失或调用失败明确显示，不伪造成功。
10. 首期采用固定采集流程，保留搜索/抓取/解析/分析服务接口供未来 Agent 调用；暂不实现采集 Agent、自主反复搜索。既有智能创作 Agent 的规划保持不变。

搜索、解析工具需经过中文目标来源样例验证再确定；动态网页渲染、登录/验证码和扫描 PDF OCR 为后续能力，不宣称任意来源可采集。详细行为及限额见 [采集增强设计](../architecture/collection-design.md)。本节在现有采集管理和素材库页面内扩展，不新增一级导航。

# 03 智能创作

## 5.1 模块定位

智能创作是平台的核心AI模块。

它不只是一个AI写作工具，而是能够自动读取素材库、分析信息、提取主题、组织内容并生成微信公众号文章的智能创作中心。

智能创作需要与采集管理和素材库建立真实的数据关联。

## 5.2 页面组成

### A. 创作任务概览

- 自动创作任务数量
- 正在执行任务数量
- 今日生成文章数量
- 待审核文章数量
- 创作失败数量

### B. 创作方式

提供三种创作方式：

1. 自动创作
2. 素材创作
3. 主题创作

**自动创作：**

系统根据自动创作规则，在采集完成、定时到达或素材数量达到条件时自动执行。

**素材创作：**

运营人员从素材库选择素材，AI根据所选素材生成文章。

**主题创作：**

运营人员输入文章主题，AI从素材库检索相关资料，再根据资料生成文章。

### C. 自动创作规则配置

配置字段：

- 规则名称
- 关联采集任务
- 触发方式
- 素材筛选条件
- 素材相关性要求
- 素材时间范围
- 每篇文章参考素材数量
- 每批生成文章数量
- 文章类型
- 写作风格
- 文章字数
- AI模型
- 创作提示词
- 是否启用规则

支持的触发方式：

1. 采集任务完成后触发。
2. 每天固定时间触发。
3. 新增有效素材达到指定数量后触发。
4. 人工点击立即创作。

### D. 素材来源选择

支持：

- 选择最近新增素材
- 选择指定采集任务的素材
- 选择指定时间范围的素材
- 从全部素材库检索
- 手动勾选素材
- 新素材与历史素材组合使用

素材展示字段：

- 素材标题
- 素材类型
- 来源
- 采集时间
- 素材标签
- 使用状态
- 关联创作记录

### E. AI智能分析

AI执行以下操作：

1. 阅读素材内容。
2. 提取核心信息。
3. 识别事件和主题。
4. 提取关键观点。
5. 提取事实、数据和引用来源。
6. 识别重复信息。
7. 分析素材之间的关联。
8. 推荐适合创作的文章主题。
9. 判断素材是否满足创作条件。

### F. 文章生成

支持AI生成：

- 文章标题
- 多个备选标题
- 文章摘要
- 文章大纲
- 文章正文
- 文章关键词
- 封面图片建议

支持内容优化：

- 续写
- 扩写
- 缩写
- 润色
- 改写
- 标题优化
- 摘要生成

### G. 创作结果管理

展示：

- 文章标题
- 创作任务
- 使用素材数量
- 创作时间
- 创作方式
- 创作状态
- 生成结果

支持：

- 查看文章
- 重新生成
- 编辑内容
- 保存草稿
- 提交内容管理
- 查看素材引用记录

## 5.3 自动创作触发逻辑

推荐默认工作流：

采集与正文提取 → 去重和可选 LLM 素材分析 → 满足条件的新素材入库并就绪 → AI判断创作条件 → AI分析主题 → 自动生成文章 → 保存到内容管理待审核。基础素材分析可复用，但不替代创作前的条件检查与主题组织。

如果素材数量不足、相关性较低或内容质量不满足条件，则暂不创作，继续积累素材。

## 5.4 自动创作素材策略

提供三种素材策略：

**策略一：仅使用新增素材**

只读取本次新采集并通过筛选的素材。

适合每日新闻、热点快讯。

**策略二：新素材与历史未使用素材组合**

优先使用新素材，同时补充相关的历史素材。

适合每日行业资讯和综合报道。

**策略三：从全部素材库智能检索**

从整个素材库中检索与主题最相关的素材，不受是否使用过的限制。

适合专题报道、深度分析和行业研究。

默认推荐第二种策略。

7. 发布成功后更新文章状态并记录发布结果。
8. 发布失败后支持查看原因和重新操作。

# 05 素材库

## 7.1 模块定位

素材库是平台的中央内容资产管理中心。

负责长期保存采集信息、人工上传资料以及其他创作辅助资料，为AI创作提供可检索、可复用的数据资源。

素材库不是未使用素材仓库，已经用于创作的素材仍然保留，可以重复使用。

## 7.2 素材来源

素材主要来自：

1. 采集管理自动入库。
2. 采集结果人工选择入库。
3. 人工上传文档和图片。
4. 手动添加网页链接。
5. 手动录入文字内容。

- 标签管理

- 下载素材
- 搜索素材
- 批量操作
- 加入创作

## 7.4 素材状态管理

每条素材需要有独立的状态：

- 待筛选
- 待使用
- 已使用
- 部分使用
- 已归档
- 重复素材

状态说明：

已使用不代表不可再次使用。

一条素材可以被多篇文章引用，系统应记录素材与文章之间的关联关系。

重复素材原则上不重复创建，但如果出现同一事件的新进展，应保留新增内容，并关联历史素材。

## 7.5 素材持续更新机制

采集任务每次完成后：

1. 接收本次采集的新信息。
2. 与历史素材进行重复比对。
3. 识别真正新增的信息。
4. 按配置调用 LLM 提取摘要、分类标签、相关性与关键事实，保留正文依据和分析版本。
5. 满足时间、去重及可选分析条件且开启自动入库时保存到素材库；其余保留结果供人工筛选，原始内容不丢弃。
6. 未完成分析或不确定资料只能明确保留为待筛选；满足条件或经人工确认后标记可用，重复处理不重复建素材。
7. 供下一轮AI创作调用。

旧素材不因被使用而删除。

# 四、核心业务流程

## 11.1 自动采集到自动创作

1. 运营人员配置采集任务。
2. 系统按计划执行采集。
3. 采集结果自动进入素材处理流程。
4. 系统识别重复信息和新增信息。
5. 新素材自动保存到素材库。
6. 系统根据自动创作规则判断是否触发创作。
7. AI从新素材和历史素材中检索相关资料。
8. AI分析素材并归纳文章主题。
9. 自动生成文章标题、大纲和正文。
10. 文章自动保存到内容管理，状态为待审核。

## 11.2 人工审核到公众号发布

1. 审核人员进入内容管理。
2. 查看AI生成的文章。
3. 检查文章内容和素材来源。
4. 必要时修改标题、正文和图片。
5. 完成排版和手机预览。
6. 点击审核通过。
7. 运营人员选择公众号。
8. 确认发布方式和发布时间。
9. 执行发布。
10. 系统记录发布结果。
11. 数据进入统计分析。

## 11.3 素材持续积累和重复利用

1. 新采集信息进入素材处理流程。
2. 系统与历史素材比对。
3. 真正新增的信息进入素材库。
4. 旧素材保留，不因使用过而删除。
5. AI创作时根据主题检索相关素材。
6. 新旧素材可以组合使用。
7. 每篇文章记录引用的素材。
8. 同一素材可以被多篇文章复用。

# 七、自动化规则和异常处理

## 14.1 自动创作触发规则

支持四种触发方式：

- 采集任务完成后触发
- 定时触发
- 素材数量达到条件后触发
- 人工立即触发

## 14.2 创作条件判断

AI创作前检查：

- 是否存在新增素材
- 是否达到最低素材数量
- 素材相关性是否达标
- 是否存在可用正文
- 是否已经生成过相同主题文章
- 是否存在尚未处理的创作任务

如果条件不满足，则不启动创作，并记录原因。

## 14.3 异常处理

需要支持：

- 采集失败重试
- 素材解析失败提示
- AI生成失败重试
- 重复任务识别
- 发布失败记录
- 微信授权异常提醒
- 任务运行日志

自动化任务需要支持执行记录和幂等控制，避免重复触发造成重复文章。

# 十、产品最终定位

智媒助手不是单纯的微信公众号编辑器，也不是单纯的AI写作工具。

它是一套完整的微信公众号智能内容生产与运营管理平台。

核心业务逻辑：

**采集管理负责获取信息，素材库负责积累内容资产，智能创作负责分析和生成文章，内容管理负责编辑审核和发布，账号管理负责微信公众号授权，数据统计分析负责评估运营效果。**

系统默认采用：

**前半段自动化生产，后半段人工审核把关。**

最终实现：

采集自动化、素材资产化、创作智能化、审核规范化、发布可控化、运营数据化。
