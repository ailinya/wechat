# 阶段8：工作台、统计与系统管理

2026-11-19；依据用户“继续执行任务8”，沿用OpenSpec project-development-roadmap。实现范围8.1–8.11；个人订阅号使用已验收的草稿同步/手动发布分支，7.13官方API发布限制不被本阶段绕过。统计设计见 [运营设计](../architecture/operations-design.md)。

## 已落地能力

- 工作台从采集结果、素材、文章、执行任务、发布单和草稿交付聚合概览、最近文章、动态、待办及异常；只返回当前用户有业务读取权限的数据，快捷入口沿用八模块。平台名称/标识/介绍/时区由持久设置驱动。
- 六类报表：采集（数量/来源/任务）、素材（新增/类型/来源/文章复用）、创作（逻辑任务/规则/产出/尝试）、人工审核（历史记录/通过率）、接口发布/草稿/人工登记、公众号实际可用指标。报表/趋势/汇总/分组/完整CSV共用事实和过滤；读取在可重复读快照中，避免同一次响应内分页和汇总不一致。
- 时间使用IANA时区本地[start_date,end_date)，结束日期不包含，最多366天；不同类型有明确维度矩阵，不支持的账号/任务组合422。逻辑创作任务重试不增加文章数；素材引用按不同文章去重；草稿同步不进入发布成功率分母，人工登记单独来源。CSV安全处理公式前缀，超过50000行明确拒绝并要求缩小范围。
- 微信运营指标只读手动采集；个人号无权限/微信无记录/字段缺失均保留不可用和NULL，实际0值可用时才显示0。采集时间和外部图文ID可查，未可靠对应人工文章时不强行绑定；群发累计数据不假称实时或全部文章运营数据。
- 平台设置版本防覆盖；用户新建、编辑、联系方式、启停、角色分配和角色权限管理复用现有API并补审计。模型/搜索新增、启停、现有配置编辑和连接测试复用旧模块；凭据仅受控环境变量引用且不回显。微信配置在账号页；存储/向量的运行期密钥由部署环境管理，提供安全摘要及只读存储/实际向量连接检查。
- 通知支持站内渠道，列表/未读/已读/分类偏好均按本人隔离，读时重新检查权限。相同事件和接收者唯一，重复投递无副作用；关闭期间事件不会在重新启用后补发。Beat每30秒按持久事实有界投递500条，工作台也可主动获取本人最新通知。邮件和微信外发未接入且不能启用。
- 日志按操作者/动作/对象/时间/结果分页查询，既有详情经二次保守脱敏，不输出长期密钥。异步监控跨用户查询安全运行状态，按类型/状态筛选，不暴露payload或原始异常。平台/用户/角色的重要权限拒绝留denied审计。

## 使用及部署

1. 备份业务PostgreSQL和加密密钥；核对业务DATABASE_URL后在backend执行 `uv run --env-file ../.env alembic upgrade head`，升级到0021。测试专用清库脚本不得用于业务库。
2. 发布前端并重启API、Celery Worker、Beat及outbox dispatcher。通知任务名为app.modules.async_execution.tasks.deliver_notifications；Windows Worker沿用solo池。无需接入邮件/微信外发。
3. 系统设置→平台信息配置名称、介绍、文字标识、有效IANA时区；配置版本冲突时刷新再保存。模型/搜索仅填写部署环境变量引用，不粘贴明文密钥；向量/存储配置由部署环境维护，接口页可检查实际连接。
4. 工作台的今日统计按平台时区；统计页可独立选择区间/时区和支持的维度。结束日期不含当天；点击导出下载全部相同筛选记录。账号指标为只读接口采集，权限不足如实显示不可用。
5. 用户/角色权限变更后服务端下次请求重新校验；页面可刷新权限。站内通知可在工作台或设置页调整本人偏好并获取最新；只能读取本人且当前有业务权限的通知。
6. 任务监控用于查看真实状态；发布/草稿未知结果必须到业务页面先核对，监控不提供无条件重置或取消入口。应用回退保留0021扩展表，破坏性downgrade仅在隔离测试库验证。

## 首版边界

八模块均有对应实现与验证，真实来源/模型/检索/创作证据见此前阶段；未做外部能力一律不假称成功。个人号freepublish不支持、微信运营指标取决于账号权限、外部通知尚未接入、向量与存储运行期密钥由部署环境管理。OCR、自主扩展抓取、首版全链路故障/备份/性能验收分别属于已声明边界及阶段9，智能化增强属于阶段10；未将路线图整体标记完成。
