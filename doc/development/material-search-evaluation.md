# 阶段 4 中文检索固定样例

用于验证中文切词、embedding 连通及混合排序契约。样例是合成素材，不代表新闻事实。预期候选按素材 ID 稳定排序规则中的 relevance 分数排序。

当前 `.env` 配置为 `qwen3.7-text-embedding-flash`，维度 1024，向量 API 基址为 `https://cn-beijing.maas.qianwenaiapi.com/api/v1`。2026-11-18 实测 HTTP 200，返回 1024 维，耗时 324 ms；安全证据见 [embedding 连通记录](embedding-model-live-evidence.json)。旧的 DashScope `text-embedding-v3` 401 记录不代表当前配置结果。固定候选表是关键词/混合检索验收基准，待搜索服务实现后记录实际召回及延迟。

2026-11-19 在本机独立 PostgreSQL/pgvector 测试实例、3 条合成素材上使用真实 `.env` 模型执行：三个相关查询均命中预期首位；无关查询在 `min_relevance=0.75` 下返回空结果。四次混合检索分别耗时 275、281、286、248 ms（包含模型请求）；逐项分数与修订标识见 [脱敏实测记录](material-search-live-evidence.json)。该小规模数据只用于功能基线，不能代表生产规模性能。

关键词对查询与正文执行 Unicode NFKC、大小写折叠、空白/标点归一化，CJK 连续字符切为重叠二元组，拉丁字母/数字按词项匹配。关键词分数为命中查询词项权重占比。阶段 4.1 的向量连通探针使用固定输入“中文向量维度连通性验证：人工智能与产业应用。”，请求 1024 维并只记录配置标识、HTTP 状态、耗时和实测维度；不得记录 API key 或完整向量。

排序固定为 `R=0.5*L+0.5*V`，其中 `L` 是归一化关键词分数，`V=clamp((cosine+1)/2,0,1)`。`R` 是排序相关度，不表示概率或事实可信度；同分按素材 UUID 升序。embedding 失败时关键词降级必须标记为 `keyword_only`，语义分数为 null。
