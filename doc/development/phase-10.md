# 阶段 10：实施进度与待验收事项

截至 2026-11-19，10.1–10.7 已实施：主题候选保留素材修订和原文依据；关联建议独立于人工关系，可忽略并选择用于历史检索；质量建议保留文章和素材证据；复用报表分别计算文章、修订、发布单、尝试及账号指标。建议须由用户判断，不改变人工审核或发布状态。详情、权限、成本和接口见 [设计说明](phase-10-design.md)。

自动测试覆盖迁移、证据校验、权限与 CSRF、失败后编辑、忽略关联、修订变化后旧关联失效、审核状态和报表计数；增强功能后端 12 项、固定检索对比 1 项、原有文章审核/素材检索/运营统计回归 28 项、前端 60 项测试和生产构建通过。测试使用隔离 PostgreSQL 和模拟模型，不代表真实模型效果或供应商费用。模型适配器已返回响应而建议内容校验失败时，仍保存响应中的有效 token 用量；适配器抛错时用量可能不可得，缺少价格或用量时成本未知。无外部调用的固定检索样例不产生供应商调用费用。

[固定检索对比](phase-10-search-evidence.json) 使用测试作者预设期望、四个查询及人工构造的历史关联。传感器查询的 Recall@10 从 0.5 到 1.0，其余两个正例均为 1.0，负例无命中；该小样本没有检出误命中。它仅验证离线关键词场景，单次延迟会波动，不能外推到生产检索或真实模型。

当前没有人工标注，因此尚不能评价主题相关度、质量建议的误报和漏报，也没有真实模型的延迟与费用验收。10.8 和依赖它的 10.9 保持未完成；需要后续对固定样例独立人工标注及评估，并完成首版流程和人工发布控制验收。真实微信发布未在本阶段执行或验收。
