# 阶段 7：自有公众号直连与可控发布

日期：2026-11-19。用户选择自有公众号直连。已实现并勾选 7.1–7.12；**7.13 的真实接入及账号实际权限验收仍阻塞**，本阶段不宣称真实微信发布已交付。

## 实现范围

- 使用公众号自身 AppID/AppSecret 接入；Secret 与缓存 token 使用 Fernet 加密，密钥由现有 APP_SECRET_KEY 派生。查询、错误及审计不回显凭据。stable_token 使用普通模式；缓存保留微信返回的实际到期点，不在复用时延长有效期。主动连接检测重新验证凭据。
- 连接、只读能力和发布权限分开表示。素材、草稿及发布列表采用只读接口探测；发布还要求运营在微信后台核实接口权限。执行时微信权限拒绝会更新本地不可用状态，不能将连接成功当作真实发布权限证明。
- 账号支持默认配置、重接入、解绑和同步历史。默认账号由事务锁及部分唯一索引保证最多一个。解绑保留历史；旧网络检测不会恢复已解绑账号或覆盖新配置。已补测目标账号选择及其解绑后规则仍可停用；迁移移除阶段5的目标账号必须为空限制。旧 OAuth 授权与回调路径返回 410，本模式不接收 OAuth 或微信事件回调。
- 同步永久图文，按账号/media_id/图文项防重，正文转 Markdown 并保留素材引用。每次最多400组图文，达到上限保留部分结果并明确失败；二进制素材不自动同步。已同步内容不覆盖人工修改。
- 创建发布单、运营确认及执行分开；确认/重试返回 202、resource_id、async_job_id（定时尚未到期时为 null）。参数、审核修订和目标账号固定；默认评论参数保存快照，更改账号默认配置不会改写原单。
- Worker 两次复验版本批准及账号能力，先上传图片、建立微信草稿，再持久化提交阶段并调用发布接口。提交不会自动重试；publish_id 仅表示微信受理，查询成功后才标为已发布。Beat 每30秒调度到期订单、查询已知发布任务及检测失联阶段。
- 无 publish_id 的提交超时保持 unknown，须人工填写核对依据；确认未发布后才可新增尝试。已知 publish_id 优先查询微信结果，查询失败不能转为可重试失败。每次尝试和核对保留操作者/时间，通用异步任务取消接口不能绕过订单取消边界。进入提交/等待结果阶段后禁止并发保存文章，避免复验与外部调用之间出现新版本。
- 账号页和发布页接通真实 API；支持能力说明、同步进度、规则目标账号建议、显式确认、定时、取消、核对及历史。文章列表同时展示各账号订单汇总，单账号成功不会隐藏其他账号失败。

## 真实接入清单与阻塞（7.13）

[只读连通证据](wechat-live-evidence.json) 已于2026-11-19真实验证连接成功：此前40164白名单错误已消失，AppID/AppSecret可获取调用凭据，永久图文和草稿读取接口通过。发布记录读取接口被微信拒绝（接口权限不足或停用），因此本系统暂不放行发布；不能由连接成功推断发布接口可用。用户进一步确认该账号为个人主体订阅号，无法完成企业主体微信认证。官方 freepublish/submit 文档明确订阅号仅允许企业主体已认证账号调用，因此本账号不具备官方API发布条件；此项作为外部账号能力限制记录，不再要求用户反复调整白名单。后续已完成真实测试封面上传、私有草稿写入与读回，见下方增量验收；未执行真实发布，7.13 的官方API发布验收仍受账号权限限制。

配置真实凭据后，在 backend 执行 `uv run python scripts/verify_wechat_connection.py`，凭据从被忽略的根目录 `.env` 或进程环境读取。脚本仅请求 token 和只读列表，不创建草稿或发布，证据只记录 AppID 指纹和脱敏状态。完成连通检查后，在业务环境账号页录入；不在测试替身页面录入真实凭据。真实发布另须明确授权及可审查的文章版本、账号、时间。

## 运行与恢复

1. 业务升级前备份，确认 DATABASE_URL 和 APP_SECRET_KEY 后，在 backend 执行 `uv run --env-file ../.env alembic upgrade head`。本轮只迁移独立测试库，没有迁移业务库。
2. 重启 API、Celery Worker、Beat 和 outbox dispatcher，确保加载新账号与发布 handler。Windows Worker 沿用 `--pool solo`。无需配置第三方 OAuth 回调域名。
3. 微信后台配置 API IP 白名单，并逐项检查接口权限。连接检测不是发布测试。AppSecret 轮换使用“校验并重新接入”。APP_SECRET_KEY 轮换须先迁移加密数据或重新录入所有公众号凭据。
4. 未确认订单不执行，定时到期复验。preparing/submitting 后不接受取消。进程失联时 preparing 转失败、submitting 转 unknown；unknown 禁止直接重试。有任务ID先查询，无ID到微信后台人工检查，不能确定时继续保留 unknown。
5. 已确认失败可重试并新增 attempt；成功与未知状态不可直接重试。文章改版后原单阻断，应重新审核、建单和确认。重试不覆盖历史。
6. 应用回退优先保留扩展表。破坏性 downgrade 会删除账号与发布历史，仅在空测试库验证，不用于业务回退。恢复时同时保留加密密钥、数据库和图片对象。

## 已知限制

原API发布分支使用 freepublish 发布草稿，不等同于消息群发；名称/类型来自人工资料，没有伪造自动获取的昵称或头像。发布图片支持 PNG/JPEG，正文图片小于1MB、单篇最多20张；外部图片须先上传替换。字段/正文超微信限制时明确失败，不截断已确认内容。准备阶段中断可能留下未发布的微信草稿/图片，不能据此认定已发布；未知提交始终先核对。

完整契约和官方依据见 [微信直连设计](../architecture/wechat-direct-design.md)。

个人订阅号已采用系统编辑/审核后同步草稿、后台人工发布的独立交付流程；复制/导出尚未实现。本账号真实草稿写入和读回已验证，详见下方记录。依据：[微信发布接口适用范围](https://developers.weixin.qq.com/doc/subscription/api/public/api_freepublish_submit.html)。
